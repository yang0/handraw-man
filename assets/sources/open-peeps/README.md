# Open Peeps reusable source assets

These **164 real SVG source files** are retained without modification from the Open Peeps component-atom mirror.

- **Original illustrations:** Pablo Stanley, [Open Peeps](https://www.openpeeps.com/).
- **Original creator's license declaration:** [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), see [official website](https://www.openpeeps.com/).
- **Actual bytes obtained from third-party mirror:** [jenshor/open-peeps](https://github.com/jenshor/open-peeps), commit [`816c04b7d09ac23a76c9260c7a8c818057696b9a`](https://github.com/jenshor/open-peeps/tree/816c04b7d09ac23a76c9260c7a8c818057696b9a).
- **Downloaded/checked:** 2026-11-08. Each file's actual Git Blob SHA-1 matches the pinned mirror commit.
- **Important:** The mirror has **not** been compared byte-for-byte with the gated official Gumroad bundle. Third-party modifications, if any, are not independently verified. The mirror's MIT software license is **not** the basis for licensing these assets.
- Two SVG files named `* None.svg` are omitted because they are null/empty selection placeholders, not artwork.
- **Never claim HandRaw drew these assets.** These remain clearly tagged as reused source.
- Many atoms include clothing, hairstyles, expressive faces or pose elements. Consequently **0 are marked Phase 1 pure-shape-ready by default**. Curation, segmentation and quality assessment are separate work.
- For every source file and its category, see [manifest.json](manifest.json).
- Validation command from repository root: `python3 scripts/verify_open_peeps.py`.
