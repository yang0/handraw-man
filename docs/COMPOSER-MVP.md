# Open Peeps 真实素材组合 MVP

关联：[#3](https://github.com/yang0/handraw-man/issues/3) · [顶级创作规范](../TOP_LEVEL_RULES.md)。

## 启动

在项目根目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，然后打开 `http://localhost:8000/`。也可以部署为任意静态站点，不需要数据库或 AI API。

## 已交付

- 读取实际入库的 [164 个 SVG 原件及来源清单](../assets/sources/open-peeps/manifest.json)，支持分类检索、网格浏览、分页。
- 头部合成：头部、表情、胡须、配饰。可选不使用胡须/配饰/表情，选择后即时切换图层。
- 上身 body、站立/坐姿 pose：均支持预览**真实来源的完整 SVG**；不强行拼接彼此不兼容的身体/腿部。
- 导出 `handraw-peep-recipe.json`（固定来源 commit、已选素材 ID），也支持导入该 JSON 恢复选择。
- 导出单件原 SVG；头部组合导出为包含源 SVG 图层的自包含 SVG 容器，不借程序创造人物线条。
- `npm run check`、`npm test`，新增 CI 验证。不依赖重型绘图包或 AI API。

## 叠加坐标来源及精度范围

将 [jenshor/open-peeps 中的 peep_avatar.dart](https://github.com/jenshor/open-peeps/blob/816c04b7d09ac23a76c9260c7a8c818057696b9a/packages/open_peeps/lib/src/avatar/widgets/peep_avatar.dart) 公开的嵌套组件 offsets 按 `473×567` 头部画布比例换算为图层定位数值；这是**对现有素材做缩放与放置**，不是人体几何程序绘制。

基础规格 `head=473×567`，其它层采用其源文件尺寸：`face=289×293`、`facial-hair=280×230`、`accessories=392×138`。实际设计稿若包含越界路径或不同家族的特殊外形，仍可能出现叠加错位，必须在后续真实图像审查时调整独立锚点。

## 不是什么

1. **不是**程序通过 SVG path 画出的人物，也没有任何人体几何生成算法。
2. **不是**完成了 48 个原创全身原型；源 SVG 中大量包含服饰、面部、头发或非中立姿势。
3. **不是**完整的身体和头部无缝装配器；当前头部组合 + 身体原件预览是已实现边界。
4. **不是**核验了官方 Gumroad 包与第三方镜像字节完全相同；目前仅确认本仓库文件与公开镜像 hash 一致。
5. **不是**在线已经部署的站点；GitHub 仓库代码可本地启动，公开在线访问需要另行配置部署。

## 批判性验收

- 对同一来源 commit + 相同配方输出稳定一致的 SVG 元素顺序与图层坐标。
- 更换头部/表情不能影响底层身体源文件的哈希。
- 禁止“身体缺失时用 CSS/SVG/Canvas 人工画假人”，不能为了视觉预览补造图。
