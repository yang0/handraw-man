# HandRaw Man · 产品需求文档（PRD v1.1）

状态：已执行 [顶级规范决策 #12](https://github.com/yang0/handraw-man/issues/12)；历史“程序参数化绘制 SVG 人体”的方案被撤销。
适用：[TOP_LEVEL_RULES.md](../TOP_LEVEL_RULES.md)。

## 1. 定位

下一代可开放复用、AI 原生的模块化手绘人物素材库。保留 Open Peeps“真实素材拆分与拼接”的核心思想，优化资产管理、风格一致性、混合来源与 AI 扩展能力。不以程序绘画、3D 假人或随机几何人体代替真实创作。

**创作方式有且只有两条：** 合规复用已有真实素材；或用 `gpt-image-2.6` 生成真正的图像素材，再切割与审查。最终用素材组合器把这些素材组装成新人物。

## 2. 产品边界

### Phase 1：Shape Library（唯一当前主线）

- 全身、正视、白底、黑白手绘线稿、自然中立站姿。
- 只有富有趣味、夸张、能迁移到后续拟人化扩展的人物形体与轮廓；不设置职业、性格、年龄、名字、故事、服装。
- 家族索引：`bamboo` 竹竿、`orb` 圆球、`pear` 梨、`wedge` 倒三角、`block` 方块、`sprout` 豆芽、`gourd` 葫芦、`big-head` 大头、`long-torso` 长躯、`long-legs` 长腿、`asymmetry` 不对称、`angular` 折线。
- 48 个优秀母版是**经策展检验的资产目标**（每家族目标 4 件），允许 Open Peeps CC0 原素材或其合规编辑件 + AI 新创素材；不能随机生成 48 个几何图凑数，也不能把全部素材谎称 HandRaw 原创。
- 图层组合：从可用 asset catalog 中选择身体/头/四肢等，按锚点进行位置、大小和层级调整；如部件不合适，回到素材生成/修图，而不是靠代码生成补丁轮廓。
- 用户体验：图库、来源筛选、选择部件、预览、复制/保存组合配方、导出 PNG/SVG、项目版本。

### Phase 2：Global People（后续）

- 解耦的头型、五官、表情、发质、肤色、服饰、配饰素材。
- 可以出现不同地域/文化的设计参考，但东西方不是两套固定人体模板；不将民族/国家和固定眼型/鼻形/肤色/体型绑定。
- 可混合多样外观，文化特色服饰保留设计出处；纯形体模式永远可关闭外观层。

### Phase 3：AI Creator（后续）

- AI 根据语言选真实已有素材，缺什么使用 `gpt-image-2.6` 补产素材；对 AI 输出进行分切、审查、存储和可追溯管理。
- 支持同风格多形体、局部替换、批量创作、参考素材对齐、失败显式反馈。
- 不调用或无法调用模型时，现有图库和手动组合仍必须可用；不伪造图像输出。

### Phase 4：Open Ecosystem

- SDK / CLI、HandRaw Style / Web 统一配方、社区素材审核及国际化。

## 3. 用户路径

1. 查找已有素材（Open Peeps/已审查 AI 生成），优先复用可用的高质量部件。
2. 无合适素材时，填写设计目标，由 `gpt-image-2.6` 生成完整人物或独立部件图。
3. 切割/抠图，调整连接锚点与素材尺寸，进行人工视觉/许可审核。
4. 在工作台通过图层对齐/替换/缩放/翻转把**现成部件**组合成角色。
5. 保存 `assetIds + assetVersions + transforms + layering + compositionVersion`，并导出 PNG / SVG / JSON。

## 4. 必要验收

- 任何“已完成”的角色都有真实可查看图片、源文件与来源信息，绝不允许仅有程序计算路径。
- SVG 如果存在，必须是 Open Peeps 原生 SVG、其它合法源 SVG、或对真实源图做图像矢量化，不允许代码数学绘制人体 path。
- 单一配方在资产版本不变时能重新组合出相同画面；不要求程序绘制轮廓。
- 所有可发布资产的来源/模型、许可审核状态与修改历史完整；组合结果可回读。
- 首批测试必须覆盖导入→切割/校正→注册→组合→导出的真实素材闭环。

## 5. 非目标

数学人体生成器、几何引擎、参数化 SVG 曲线路径生成、写实 3D 解剖、职业/IP 角色库、按种族套模板、一期直接建设动物库。
