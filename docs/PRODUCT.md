# HandRaw Man 产品需求文档（PRD）

状态：基线提案 v1.0，2026-11-08。对应仓库 https://github.com/yang0/handraw-man 。

## 1. 愿景

打造“全球通用的原创人物形体母库 + 参数化设计引擎 + AI 辅助设计工作流”，让创作者无需擅长绘画即可组合、设计、复用有强烈剪影辨识度的人物。复用 Open Peeps 的“部件组合”**原理**，不复刻具体素材。

受众：插画创作者、设计师、教育内容团队、手绘漫画创作者、开发者、创作平台/Skill 使用者。

## 2. 分期范围

### Phase 1 · Shape Core（现在）

- **只有人类抽象形体**：全身、正视、黑色线稿、白底、自然站姿；不加五官、发型、服饰、道具、职业和叙事身份。
- 12 个形体家族，首批目标 48 个原创母版（每家族 4 个）。阶段验收允许先交可运行的少量样板，再补齐 48 个经人工审美质检的作品，不应把程序变体冒充独立手绘母版。
- 可控参数：头身比、头宽高、颈长、肩宽、躯干宽高与收腰、手臂比例、腿长、手脚比例、左右对称/非对称、线条粗细。
- 原型画廊：分类筛选、形体对比、参数调整、随机种子、复制配方、导出 SVG/PNG。
- 结构质量：无断裂、无失控自交、自然贴地、整体入画、极端参数有边界。
- AI 在一期仅生成**受控 JSON 配方**，不可默默创建未经审核的 SVG 母版。

### Phase 2 · Global People（后续）

- 把可选头部轮廓、眼鼻口、发质发型、肤色、服装、配饰作为独立资产包，不改变 Shape Core。
- 强调东亚、东南亚、南亚、中东、非洲、欧洲、美洲等多元外观参考，但**不设“民族=固定五官/肤色/身体”的公式**。
- 地域服饰标注文化来源与许可，不将某单一装束代表整体地区。
- 支持纯形体模式随时隐藏任何外观层。

### Phase 3 · AI Studio（后续）

- 自然语言 -> JSON 设计计划 -> Schema 验证 -> 确定性 renderer -> 修正对话。
- 形体锁定、局部编辑、种子变体、批量探索；异常几何自动诊断而非生成后掩盖。
- AI 提议新增独立部件时走可追溯的审查入库流程。

### Phase 4 · Open Ecosystem（后续）

- CLI、SDK、API、HandRaw Web/Skill 集成；经审核的社区资产包和版本仓库。
- 动物拟人化是从人类 Shape DNA 衍生的**独立阶段**，不进入一期基础分类。

## 3. 12 个形体家族（仅抽象几何分类）

| ID | 形体家族 | 基本特征 |
|---|---|---|
| bamboo | 竹竿 | 细长四肢，小头窄肩 |
| orb | 圆球 | 圆躯干，紧凑肢体 |
| pear | 梨形 | 上窄下宽 |
| wedge | 倒三角 | 宽肩收腰 |
| block | 方块 | 平直、稳定、盒型 |
| sprout | 豆芽 | 小躯干，柔和延伸 |
| gourd | 葫芦 | 上下两团块收腰 |
| big-head | 大头 | 头部比重极大 |
| long-torso | 长躯 | 躯干主导 |
| long-legs | 长腿 | 腿部主导 |
| asymmetry | 不对称 | 重心与左右轮廓错位 |
| angular | 折线 | 几何转折强烈 |

家族是形体搜索索引，不是人种、职业、年龄、性格或固定人物角色。

## 4. 核心用户流程

1. 在形体画廊选择母版（或 AI 提议母版）。
2. 在正视预览中调整参数，实时反馈比例变化。
3. 保存 `shapeId + libraryVersion + renderVersion + params + seed` 配方。
4. 在画廊中比较多个种子/母版的轮廓，选中后导出 SVG/PNG/JSON。
5. 后续阶段可选择外观扩展，但原始形体始终可独立复用。

## 5. 体验原则

- 默认“无字、无装饰、无服饰、无五官”；重点是线条、轮廓和几何。
- 以全身正视图为主，不做写实 3D 假人、骨骼技术图、人体肌肉解剖图。
- 单个创作页面：左侧母版/家族、中间大画布、右侧参数；移动端渐进折叠。
- 批量生成以首图为卡片、点击展开；避免数百张相近素材占满画廊。
- 主动提示未通过质检的导出，而不是静默成功。

## 6. 非目标

一期不做角色身份库、姓名故事、种族模板、风格模仿、动态 GIF/视频、重型 3D、社区商业市场、无限画布。

## 7. 指标与验收

- 同一配方+版本+种子重复渲染字节一致；不同配方可追踪。
- 输入非法参数返回明确错误，不渲染畸形路径或 `NaN`。
- 所有一期基础母版能渲染完整形体且坐标在 viewBox 内。
- 所有产物为合法、可独立打开的 SVG；至少一组跨母版回归快照。
- 48 个原生母版需通过人工轮廓辨识度评审，不能只靠随机参数凑数。
