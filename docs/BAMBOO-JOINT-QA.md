# Bamboo-001 · 关节旋转与美术缺陷验证（Issue #14）

关联：[Issue #14](https://github.com/yang0/handraw-man/issues/14) / [Issue #5](https://github.com/yang0/handraw-man/issues/5) / [最高素材规范](../TOP_LEVEL_RULES.md)。

## 本次交付

Bamboo-001 是一张由 ChatGPT 内置生图工具生成的真实黑白人物图。目前保存了全尺寸原始 PNG、去白底源图和 **6 张真实分件 PNG**。这个里程碑解决的是**如何看见、保存和比较关节旋转后的缺口**，不等同于完成美术修复。

- [真实 PNG 装配界面](../bamboo-parts.html) 已增加按**来源锚点**旋转、位移、0.8–1.2 比例缩放、原位复位、锚点可视化。
- 预置 **neutral、arms-out、walk-test** 三种姿态，分别用于原位复核、肩关节检查、髋关节检查；预置动作只是叠放与旋转真正存在的 PNG 像素。
- [变换与数据契约](../web/part-transform.mjs) 基于来源 manifest 的 `sourceX/sourceY` 计算锚点。轴心坐标旋转前后稳定；不添加任何线条、几何曲线或人体补笔。
- 可导出、重新导入 JSON 配方；严格验证版本、真实原图 SHA-256、6 件 PNG 各自的哈希、合法锚点、角度范围、位移与草稿审核状态。
- 接缝问题支持记录 `unreviewed / visible-seam / occlusion / incomplete-outline / other`，导出缺陷报告 JSON；**没有按钮允许将未经修复的部件改成 approved**。
- 浏览器会重新读取源 PNG 字节并执行 Web Crypto SHA-256 校验，必须使用 localhost/HTTPS。
- [3 张真正的像素装配 QA 图](../assets/qa/bamboo-001/) 与 [逐件 SHA-256 记录](../assets/qa/bamboo-001/manifest.json) 已独立输出：不包含新的角色线条或结构，不能计入新的素材母版。

## 严格的证据说明

本次 QA PNG 是用 Pillow 对真实部件图片进行平移/旋转/合成生成的**诊断截图**，并非 AI 新绘制的部件。浏览器 Canvas 也只允许 `drawImage` 等现有像素图层操作；坐标旋转用于素材编辑，不是程序通过曲线绘制人体。

三种姿态检查所得图片均处于 `draft` 状态。基于原图肩膀/髋部在原画中连成一体的事实，一旦肢体移动，硬切口就可能暴露出接缝；严格拒绝把这种结果标为“可自由摆姿”或“美术通过”。

之前尝试为关节生成新的独立部件，生成器仍返回包含大量文案的演示海报，**不符合可替换的透明关节组件标准，未入库**。
