# 素材裁切与锚点工具 · Issue #5

本工具只对**真实存在的 SVG / PNG / JPG / WebP 图像**进行裁切、背景去除、锚点标注、层叠、文件导出。不使用数学几何生成任何人物轮廓。遵循 [TOP_LEVEL_RULES](../TOP_LEVEL_RULES.md)。

## 本地运行

在仓库根目录执行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000/cut-editor.html`。无需 Node 构建、Docker 或 AI API。

## GPT Image 草稿接入

在仓库根目录用 `node scripts/generate-ai-source.mjs --family bamboo` 调用真实配置的 `gpt-image-2.6`（需本地设置环境变量，详见 [AI 素材生成手册](AI-SOURCE-PIPELINE.md)）。生成成功后，当前网页的「素材来源 / 类别」选择 **AI 草稿（本机生成）**，可加载已归档原图。加载时对照记录的 SHA-256 校验真实图片字节，后续裁切 JSON 中保留 `sourceKind=ai-generated` 与生成模型/提示词信息。网页本身不获取 API Key。

## 裁切与装配流程

1. 选择 164 个 Open Peeps 已导入的 SVG 原件之一，或上传本机 PNG/JPG/WebP（最大 20MB）；自有图片需自行确认授权。
2. 在原图上拖动框选矩形。可勾选去除与图像外边界连通的近白色背景；默认阈值 245。背景移除不是 AI 语义分割，可能破坏与外边相连的白色衣物。
3. 切换至锚点标注，选择 neck、shoulderL/R、hipL/R 等，再点击选区内位置。坐标存为相对于裁切件的 0..1 值；修改裁切区会清空旧锚点。
4. 分类命名、设置 zIndex，点击加入装配区生成真实透明 PNG。必须**分别下载 PNG 和 JSON**，两者配对。
5. JSON 保存原图 SHA-256、源文件路径与 Git Blob 哈希（若有）、处理后 PNG SHA-256、裁切坐标、锚点、草稿审核状态及修订记录。
6. 装配画布只叠加已裁切的真实 PNG；可拖动、缩放、旋转、按锚点对齐。导出 PNG 与 JSON 配方。
7. 下次可重新选择 PNG+JSON 配对导入装配区，系统验证 PNG SHA-256 与尺寸是否与元数据一致。

## 安全与限制

- 源图不改写，SVG 原件会经浏览器栅格化为 PNG；导出 PNG 不宣称是可编辑 SVG。
- 本地用户图像留在浏览器会话，不会自动保存到 GitHub；需自行保存源图。
- SHA-256 由浏览器 Web Crypto 实际计算，需要 localhost 或 HTTPS 环境。
- 图像处理最高 1600 万裁切像素、源图不超过 3200 万像素；超过限制会报错。
- 背景去除只能删除外边界连通白色像素，不能自动恢复被遮挡的身体部件。
- 所有切割件默认为 draft、phase1Ready=false。只有美术、授权与连接审核后才能进入正式形体库。
- 当前仅提供人工裁切与锚点对齐工具；尚未提供全身人体语义分割、自动去衣服或真正的 AI 生图。
- 自动单元测试与素材来源集成测试不能替代浏览器端视觉回归；人工查看边缘、锚点和遮挡仍是必须验收步骤。
